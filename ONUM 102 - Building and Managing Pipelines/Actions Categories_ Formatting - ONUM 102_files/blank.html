Actions Categories: Formatting

Formatting Actions in Data Pipelines

This module discusses the Message Builder component, which is an important and singular formatting action used to configure the message sent to a destination, ensuring it is in the format the destination expects.

Pipelines always begin with a Listener's Label. Listeners do not have their own configuration inside the pipeline; all configuration is done in the "Listeners" menu when are created and configured.

Understanding the Message Builder Action

The Message Builder displays all fields generated throughout the data flow that are available to build a message. These field values, including all values from the beginning of the flow, can be dragged into the lower box to compose the message. When a delimiter is set, the separator is automatically included each time a new value is added.

The Message Builder offers flexibility, allowing messages to be human-readable, for example, by combining text with a field value, or constructing a JSON document or a key-value structure. This allows users to choose the most suitable format for their needs.

The message builder also allows specification of how to handle situations where a delimiter matches a character in a field. Options for handling this include:

  • Escaping the character with a backslash.

  • Replacing the character with another value.

  • Wrapping the field in quotes.

  • Removing the character altogether, which results in the most loss of information.

Typically, a data sink action is preceded by the Message Builder to send data to a destination.

The expressions should be strings that, optionally, may contain field names.

For example:

where ${myField} will be replaced with the actual value in the event.

The action provides the following features depending on the argument delimiter behavior and the given delimiter and replacement values:

  • REPLACE: replaces delimiter with replacement on each event field.

  • DELETE: deletes delimiter on each event field.

  • QUOTE: adds double quotes surrounding an event field if it contains delimiter.

  • ESCAPE: adds a backslash (\) before each delimiter on each event field.

To select more than one at once, click a field in the Fields area and select the checkboxes next to the name, then select Add fields.

Conclusion

The Message Builder is a pivotal tool for formatting data within a pipeline. It allows users to structure messages for various outputs, such as CSV or JSON, ensuring compatibility with different data sinks. By leveraging its intuitive interface, users can easily define the format and structure of their data, streamlining the integration process and reducing errors.

One of the key features of the Message Builder is its drag-and-drop functionality, which simplifies the creation of complex message formats. Additionally, it provides options to handle delimiters effectively, such as escaping or replacing characters, to maintain data integrity. Mastering these features empowers users to create efficient and adaptable pipelines tailored to specific needs.
