Key benefits of the workbench include:

    Unified visibility across your security stack

  • •

    Real-time collaboration capabilities

  • •

    AI-powered investigation assistance

  • •

    Integrated response actions

  • •

    Comprehensive documentation and audit trail

Review the following section to learn more about workbench use cases 

  • Incident investigation

    Security analysts use the workbench to:

    • Visualize the full scope of an incident through interactive graphs

    • Track incident chronology with the timeline feature

    • Enrich entities with threat intelligence and asset data

    • Search across all related event data

    • Document findings and share insights with the team

  • Threat hunting

    Threat hunters leverage the workbench to:

    • Search for suspicious patterns across their environment

    • Add custom nodes and relationships to track investigation paths

    • Use Charlotte AI to identify hidden connections

    • Create and share investigation templates

    • Document and export findings for broader team awareness

  • Incident response

    Response teams utilize the workbench to:

    • Execute response actions directly from the interface

    • Trigger automated workflows through Fusion SOAR

    • Track response activities in real-time

    • Document response procedures

    • Maintain chain of custody for investigations

  • Team collaboration

    Security teams collaborate through:

    • Real-time multi-user investigation

    • Shared notes and findings

    • User tagging for notifications

    • Incident locking for focused investigation

    • Version control of investigation states
