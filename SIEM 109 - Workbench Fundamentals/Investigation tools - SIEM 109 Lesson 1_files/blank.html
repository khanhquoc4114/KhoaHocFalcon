AI-generated summaries

When you analyze a case or incident in the Workbench, Charlotte AI can generate a concise, natural language summary of the key findings, context, and relevant details. This helps analysts quickly understand the scope and critical aspects of an incident or case without manually sifting through all the raw data.

  1. In the Case or Incident Workbench, you can invoke Charlotte AI to analyze the current case or incident.

  2. The AI will return a summary, which you can optionally add to the case or incident record for documentation and collaboration purposes.

  3. These summaries are especially useful when multiple team members are involved, providing a shared, easy-to-understand overview.

CrowdStrike Asset graph

The CrowdStrike Asset graph serves as one of several data enrichment sources available in the workbench. When investigating an entity (like a host, user, or process), analysts can enrich that entity with additional context from the Asset graph to:

  • Understand asset relationships

  • View configuration details

  • Check vulnerability status

  • See historical changes

  • Add relevant asset context to the investigation
