4 of 5
Step 3

Creating and updating prevention policies

You have a few options when it comes to creating or updating prevention policies.

The "Phase 1", "Phase 2", and "Phase 3" policies are defaults that are created when a new CID is provisioned. Existing Falcon customers may not have these platform default policies.

To update the prevention policies, you can:

  • Update an existing policy

  • Duplicate and update an existing policy

  • Create a new policy in the console

  • Import an existing policy via API

    • PSFalcon: https://github.com/CrowdStrike/psfalcon/wiki/Prevention-Policies(opens in a new tab)

    • Falcon Toolkit: https://github.com/CrowdStrike/Falcon-Toolkit?tab=readme-ov-file#policy-manipulation(opens in a new tab)

    • FalconPy: https://github.com/CrowdStrike/falconpy/tree/main/samples/prevention_policy#clone-prevention-policy(opens in a new tab)
