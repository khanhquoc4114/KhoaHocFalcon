Basic workflow elements: Conditions

Workflows can be refined by adding one or more conditions.

The Condition is coupled with a purple icon that has 2 diverging arrows.

Access both tabs below to learn more about the AND and OR operators you can specify when adding more than one condition. 

With AND operators, the overall workflow condition evaluates to true only if all included conditions are true. 

In the example below:

  • When the workflow gets an endpoint protection detection it will only send an email when the severity is greater than or equal to high AND the Host groups include specified host groups. 

  • Any high severity detections that do not include the specified Host groups would not send an email.

With OR operators, the overall workflow condition evaluates to true if any one or more conditions are true.

In the example below, when the Falcon platform gets an endpoint protection detection it will send an email if:

  • Just the severity is greater than or equal to high OR 

  • Just the tactic includes specific Host groups OR 

  • Both conditions are true
