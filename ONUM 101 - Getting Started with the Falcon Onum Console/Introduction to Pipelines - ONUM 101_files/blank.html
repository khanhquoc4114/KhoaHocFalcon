Introduction to Pipelines

How Falcon Onum streamlines your data

Use Pipelines to transform your events and build a data flow linking Actions, through inputs/outputs, from Listeners to Data sinks.

The Pipelines menu view is similar to those for Listeners and Data Sinks. This consistent design helps users navigate the console more quickly and interact with menus more intuitively.

Because the Pipelines menu works the same way as Listeners and Data Sinks, filtering functions similarly. Here the graph displays both input and output data, and below the filters you'll find 3 metrics showing your Pipeline data volumes..

  1. Listeners: Events per second (EPS) ingested by all Listeners in your Pipelines for the selected time range, as well as the difference in percentage compared to the previous lapse.

  2. Data Sinks: Events per second (EPS) sent by all Data Sinks in your Pipelines for the selected time range, as well as the difference in percentage compared to the previous.

  3. Data Volume: See the overall data volume processed by all Pipelines for the selected time range, and the difference in percentage with the previous.

Pipeline detail view

Click a Pipeline to open its settings in the right panel, where you can view versions and edit the Pipeline.

The details panel is split into three tabs showing the Pipeline at different statuses:

Tab

Description

Running

This is the main tab, where you can see details of the Pipeline versions that are currently running.

Select the drop-down next to the Pipeline version name to see which clusters the Pipeline is currently running in.

Draft

Check the details of the draft versions of your Pipeline.

Stopped

Check the details of the version of your Pipeline that are currently stopped.

Click the ellipses in the top right to Copy ID or Duplicate/Remove it.

Once you have located the Pipeline to work with, click Edit Pipeline to open it.

Conclusion

In this module we have seen how the Pipelines Menu provides a comprehensive overview of your data pipelines once they are created in the console. It allows you to monitor key metrics such as events per second and total data volume, offering valuable insights into pipeline performance. This information helps identify trends and optimize data flow effectively.

Additionally, the menu includes tools to view the status and details of individual pipeline versions. Filters can be applied to focus on specific pipelines, making it easier to manage and analyze relevant data. By utilizing these features, you can maintain better control and visibility over your data processes.
