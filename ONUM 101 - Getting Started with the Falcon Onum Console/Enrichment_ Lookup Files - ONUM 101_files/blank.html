Enrichment: Lookup Files

Falcon Onum's Lookup Files enhance data in motion

Falcon Onum's enrichment feature allows you to load tables and use them as lookup files to enhance data in motion by adding relevant/contextual information from external sources to the data streams flowing within the Pipelines.

Use the Action Lookup in your Pipelines to enrich your information. There, you'll be able to select any of the lookups in your Tenant.

Conclusion

The Falcon Onum Enrichment feature empowers users to enhance their data streams by utilizing lookup tables. This tool allows for the addition of contextual information, improving data quality and relevance. Here are some key takeaways:

  • •

    Lookup tables/files. They enrich data by adding external information to your Pipelines.

  • •

    Upload and manage lookups. You can create, update, and tag lookup versions without losing previous data.

  • •

    Designate a key column. This ensures accurate data matching and enrichment.

  • •

    Filter and organize lookups. Apply filters or tags to streamline lookup management.

  • •

    Download/Upload lookup versions. Update to the latest or Access to previous CSV files versions.

  • •

    Remove outdated lookups. Easily delete unnecessary lookup tables when needed.
